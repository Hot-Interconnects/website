The underlying minimal routing tables can be built using standard mechanisms, but what changes is how packets are forwarded. Usually, standard routings do 1 lookup to the routing table. Polarized routing needs 2 lookups of the minimal routing table: one querying the source and the other for the destination. It requires both to compute the correct ports.
